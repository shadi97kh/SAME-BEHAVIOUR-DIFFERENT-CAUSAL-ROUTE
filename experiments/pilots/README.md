# Exploratory and superseded notebooks

No paper result depends on anything in this directory. These notebooks are kept so the
provenance of the released experiments is visible; they are not maintained, and some were
written for a platform-specific environment.

| File | What it is |
| --- | --- |
| `falcon/falcon_h1_route_screen.ipynb` | early Falcon-H1 route screen; superseded by `experiments/appendix_e_falcon_h1/` |
| `falcon/falcon_h1_steering_pilot.ipynb` | Falcon-H1 steering attempt; no steering claim is made from it in the paper |
| `language_model/tinystories_lm_pilot_superseded.ipynb` | first TinyStories language-model attempt, incomplete; superseded by `experiments/tinystories_lm/` |
| `language_model/hybrid_lm_scale_colab.ipynb` | language-model scaling pilot; contains an unfinished auto-generated draft cell |
| `language_model/lm_smdr.ipynb`, `language_model/lm_parallel_route_gate2.ipynb` | WikiText-2 route pilots |
